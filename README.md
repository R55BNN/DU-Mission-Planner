# Dual Universe Mission Planner

Static web app. Works offline and on GitHub Pages.

## Quick start (GitHub Desktop)
1. **File → New repository…** (e.g., `du-mission-planner`) and choose a local folder.
2. Copy these files into that folder (keep **`index.html`** at repo root and the **`assets/`** folder next to it).
3. In GitHub Desktop: commit with message “Initial site” → **Publish repository** (**Public**).
4. On GitHub.com → **Settings → Pages** → **Deploy from a branch**; **Branch:** `main` (root). Save.
5. Your site will be at:  
   `https://<YOUR-USERNAME>.github.io/<REPO-NAME>/`

> If you see 404 at first, give it ~1 min then refresh.

## Develop
- Edit `index.html`, `styles.css`, `app.js` and commit/push. GitHub Pages redeploys automatically.
- Keep the `/assets` folder paths unchanged.

## Notes
- Distances use official DU values, cruising speed 50,000 km/h.
- No warp planning (text removed), overfilling allowed with warnings.
- Light/Dark theme toggle, persistent via `localStorage`.
- Branding links:
  - Top-left TerraVerse logo → your Discord.
  - Top-right DU TV logo → thethirdverse.net.

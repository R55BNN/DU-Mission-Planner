Quick Start Quick steps ▼
  1. Start/End: choose your starting and ending planets.
  2. Ship volume: set Ship Capacity (kL). It’s used for warnings; overfilling is allowed.
  3. Time Budget: set hours then tick the box. The planner adds legs only while elapsed time + a return to your end planet fits the budget; otherwise it stops. The summary shows unused time.
  4. Select missions: filter with search, then tick the checkboxes. Only selected missions are planned.
  5. Plan Route: optimizer collects from your current planet and orders drops for best q/hr.
  6. Fly it: each leg shows volume before → after; red highlight = over capacity. Use Clear route or Export CSV anytime.
